MYPOKER TOURNAMENT 1.2.0 - WINDOWS RELEASE CANDIDATE
=============================================================

RELEASE PACKAGE
---------------
- Windows installer source package using PyInstaller and Inno Setup
- Dedicated application icon applied to the executable, window/taskbar where supported, installer, and shortcuts
- Branded installer artwork and manual cover banner
- Offline in-app Help, contextual F1 Help, PDF user guide, and editable Word manual
- Bundled Long Gong blind-start sound and One Minute low-time warning

TOURNAMENT FEATURES
-------------------
- Scenario Manager and New Scenario Wizard for reusable tournament setups
- Standard, Charity, Home Game, and Freeroll starting configurations; Charity and Freeroll are independent options
- Count-based player/entry/rebuy/add-on tracking
- Traditional, mixed fixed-dollar/percentage, and fixed freeroll payout modes
- Mixed-payout safety validation and fallback to traditional percentages when necessary
- Paid-position rules and charity maximum paid-place option
- Blind structure editor/import, breaks, automatic transitions, pause-after-break option, and time adjustments
- Adjustable main-window size and full-screen TV display with a time-remaining pie chart

INSTALLATION
------------
The distributed installer is built on a Windows runner from this source package. The installed app is bundled with its Python runtime, so Python is not required on the PC running the installed app. The installer creates a Start Menu shortcut and can create a desktop shortcut.

KNOWN LIMITATIONS / PRE-LIVE CHECKS
-----------------------------------
- The first release is unsigned, so Windows may display a SmartScreen or antivirus warning.
- The session archive is saved as JSON; this release does not include a dedicated archive browser/restore interface.
- Test gong and warning playback on the actual tournament PC and audio output device.
- Test player/entry counts, one level transition, the low-time warning, and payout calculations before a live event.
- Back up mypoker_tournament.json, mypoker_tournament_scenarios.json, and mypoker_tournament_sessions.json before updating.

MYPOKER TOURNAMENT v1.2.0 — CUSTOMER RELEASE CHANGES
---------------------------------------------------
- Customer-facing release version is 1.2.0; internal development baseline is v64.11.
- Statistics & Reports is hidden from the main navigation. Its underlying code is retained for possible future use.

- Modern control font size is limited to 8–15 pt and button scaling to 75–150%; Modern show/hide controls switch instantly without animation.
